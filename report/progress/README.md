# Final report

Compile `main.tex` with **XeLaTeX** in Overleaf. The folder is self-contained:

- `sections/` contains the eight report chapters.
- `references.tex` contains the bibliography.
- `figures/` contains the generated evaluation figures.
- `fonts/` contains the Noto Sans Thai fonts required by XeLaTeX.

The figures are generated from the project's saved evaluation CSV files. The datasets and
external methods are cited in the report; the figures are project-generated rather than copied
from an external publication.
